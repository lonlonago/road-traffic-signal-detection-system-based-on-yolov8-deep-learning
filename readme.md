# Road traffic signal detection system based on YOLOv8 deep learning

## Body

Based on the YOLOv8 deep learning framework, this project has developed an efficient and accurate road traffic signal detection system. It can recognize 21 common road traffic signs and signals. The system is trained using a carefully constructed dedicated dataset, which includes 1376 training images, 488 validation images, and 229 test images, totaling 2093 labeled images. This system can detect various traffic signals in real-time, including traffic light (red, yellow, green), prohibition signs (prohibited entry, prohibited parking, prohibited turning, etc.), and indication signs (bus stop, pedestrian crossing, railway crossing, etc.). It provides key technical support for intelligent transportation systems, autonomous driving assistance, and traffic monitoring. Experimental results show that the system achieves high detection accuracy and real-time performance on the test set, meeting the practical application needs.
